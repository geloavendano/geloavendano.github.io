# Handbook build templates

Copy these files into a new repository's `docs/` folder and fill them in before
or during the first vertical slice. They are intentionally short: decisions
that need a long explanation should link to a separate document.

- `prebuild-decisions.md` — answer the ten pre-build questions and route the outputs
- `stack-plan.md` — fill every layer of the full stack and record scale assumptions
- `app-brief.md` — user, problem, critical flow, and success measure
- `data-dictionary.md` — core entities and exact field meanings
- `feature-xray.md` — trace one feature from click to stored result
- `decision-record.md` — record a hard-to-reverse choice and its trade-offs
- `release-checklist.md` — evidence required before calling a change shipped
- `production-readiness.md` — uptime, volume, limits, recovery, security, and incident readiness
