The Build So Far

A hands-on guide to how the projects in ~/Projects actually work — so the code is understandable, the AI’s work is reviewable, and the next app starts from better decisions.

Goal 1: understand what is being built.   Goal 2: build the next app faster and more deliberately.

This is a working handbook and a practice space. Read explanations, then follow the source trails into the real repositories, predict what the code will do, make safe local changes, and verify them. The point is not to memorize every tool; it is to know how to find the rule, identify which layer owns it, and prove a change works.

Use Concepts for the mental model, Deep-dives for guided feature X-rays, Build playbook when starting or shipping, AI development to keep agent work reviewable, and Tools as an appendix when designing a screen.
